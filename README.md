# Умный дом

Учебный проект по практической работе №1 — статическая модель системы «Умный дом». Система управляет устройствами в квартире: светом, замками, климатом — и следит за состоянием датчиков (протечки, движения). Пользователи взаимодействуют с домом через Телеграм-бот или голосом через встроенный модуль «Джарвис». Жильцы настраивают сценарии автоматизации и активируют режим «никого нет», при котором система переходит в режим охраны. При срабатывании аварийного датчика система формирует уведомление, доставляет его жильцу и при необходимости передаёт сигнал в полицию. Доступ к устройствам разграничен по ролям: взрослый жилец имеет полные права, ребёнок — ограниченные с возможностью временной эскалации привилегий, техник — доступ только к обслуживанию. Уведомления доставляются через основной канал (Телеграм) с резервным каналом на случай ограничений доступа. Модель построена по методологии diagram-as-code: все диаграммы хранятся в виде `.puml`-исходников и собираются в PlantUML.

## Структура репозитория

- `docs/00-setup/` — настройка среды, черновики диаграмм, рефлексия.
- `docs/01-usecase/` — актёры, диаграмма вариантов использования, сценарии, трассировка на FURPS+.
- `docs/02-domain/` — модель предметной области: кандидаты в классы, диаграмма классов, обоснования решений, диаграмма объектов.
- `_style.puml` — общий стиль для всех диаграмм.
