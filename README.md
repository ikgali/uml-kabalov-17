# Умный дом

Учебный проект по практическим работам №1–2: статическая и динамическая модели системы «Умный дом». Система управляет устройствами в квартире: светом, замками, климатом — и следит за состоянием датчиков (протечки, движения, дыма). Пользователи взаимодействуют с домом через Телеграм-бот или голосом через встроенный модуль «Джарвис». Жильцы настраивают сценарии автоматизации и активируют режим «никого нет», при котором система переходит в режим охраны. При срабатывании аварийного датчика система формирует уведомление, доставляет его жильцу и при необходимости передаёт сигнал в полицию. Доступ к устройствам разграничен по ролям: взрослый жилец имеет полные права, ребёнок — ограниченные с возможностью временной эскалации привилегий, техник — доступ только к обслуживанию. Уведомления доставляются через основной канал (Телеграм) с резервным каналом на случай ограничений доступа. Модель построена по методологии diagram-as-code: все диаграммы хранятся в виде `.puml`-исходников и собираются в PlantUML.

## Структура репозитория

- `docs/00-setup/` — настройка среды, черновики диаграмм, рефлексия.
- `docs/01-usecase/` — актёры, диаграмма вариантов использования, сценарии, трассировка на FURPS+.
- `docs/02-domain/` — модель предметной области: кандидаты в классы, диаграмма классов, обоснования решений, диаграмма объектов.
- `docs/03-sequence/` — диаграммы последовательности и коммуникации для ВИ-01, сравнение нотаций.
- `docs/04-activity/` — процесс активации режима «Никого нет» с дорожками и поток объекта `Сценарий`.
- `docs/05-state/` — конечный автомат жизненного цикла `Сценария`, таблица переходов и выводы.
- `_style.puml` — общий стиль для всех диаграмм.
