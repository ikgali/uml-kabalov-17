A-- B : ассоциация
A--> B : направленная ассоциация
A o-- B : агрегация (A — общее целое)
A *-- B : композиция (A владеет B)
A ..> B : зависимость
A--|> B : обобщение (A наследует B)
A ..|> B : реализация интерфейса
Порядок по силе связи, от слабой к сильной: зависимость → ассоциация → агрегация →
композиция
