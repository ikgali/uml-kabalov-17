# Трассировка ВИ на требования FURPS+

| ВИ | Функциональное | Нефункциональное (категория) |
|---|---|---|
| ВИ-01 Управлять устройством | изменить состояние устройства по команде жильца | отклик на команду ≤ 1 с при 50 активных устройствах (Performance) |
| ВИ-02 Проверить права доступа | определить, разрешена ли операция текущей роли | проверка прав не должна добавлять более 50 мс к обработке команды (Performance) |
| ВИ-03 Настроить сценарий | создать и сохранить правила автоматизации | интерфейс настройки доступен с мобильного и с десктопа (Usability) |
| ВИ-04 Активировать режим «никого нет» | перевести систему в режим охраны | при отключении электроэнергии режим сохраняется и восстанавливается после перезапуска (Reliability) |
| ВИ-05 Получать уведомления | доставить сообщение о событии жильцу | аварийное уведомление доставляется ≤ 30 с с момента события; при недоступности основного канала задействуется резервный (Reliability) |
| ВИ-06 Получить уведомление об аварии | сформировать и отправить уведомление при срабатывании аварийного датчика | при недоступности Телеграм-бота сообщение ставится в очередь и повторяется с экспоненциальной задержкой (Reliability) |
| ВИ-07 Передать сигнал в полицию | передать сигнал о происшествии во внешнюю систему | канал передачи сигнала защищён шифрованием; факт передачи журналируется 3 года (Supportability) |
| ВИ-08 Запросить повышение привилегий | временно расширить права ребёнка до взрослого | повышение действует не более N минут и автоматически откатывается по истечении (Reliability) |
| ВИ-09 Просмотреть историю событий | показать журнал событий за период | поиск по журналу за 30 дней — не более 2 с при 10⁵ записях (Performance) |
| ВИ-10 Обновить ПО устройства | установить новую версию прошивки | обновление выполняется без потери текущих настроек; при сбое — автоматический откат к предыдущей версии (Reliability) |
| ВИ-11 Диагностировать устройство | получить сведения о состоянии устройства | диагностика не прерывает работу устройства (Reliability) |
